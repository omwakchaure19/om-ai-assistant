# 🤖 Om AI Assistant

AI Chatbot + PDF Assistant built using Python, Streamlit, and Ollama.

## Features

- 💬 AI Chatbot
- 📄 PDF Upload & Question Answering
- 💾 Save Chat
- 🗑️ Clear Chat
- 📊 Message Counter
- 🖥️ Local AI using Ollama
- 🔒 No API costs

## Tech Stack

- Python
- Streamlit
- Ollama
- Qwen 2.5 (0.5B)
- PyPDF

## Run Locally

Install dependencies:

pip install streamlit requests pypdf

Run:

py -m streamlit run app.py
